Introduction

L’agent reçoit les journaux locaux et les transmet en HTTPS.

Configuration du collecteur

Indiquez une origine HTTPS publique et, au besoin, un token.

Configuration de Log Center

Destination 127.0.0.1, TCP 5514, IETF RFC5424, SSL local désactivé.

Tester la connexion

Le test classe DNS, TCP, TLS, certificat, HTTP et authentification.

Buffer et conservation

Maximum 128 MB; les plus anciens événements peuvent être supprimés à la limite.

Dépannage

Vérifiez le statut, le certificat et l’accès Internet du NAS.

Informations de version

IDNNOV Log Agent 1.0.0-1001, DSM 7.3, DS920+ geminilake.
