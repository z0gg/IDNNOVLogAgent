Configuration OpenObserve

Chaque événement contient idnnov_company, idnnov_nas et idnnov_device_id. Dans OpenObserve, filtrez notamment idnnov_nas = 'GRLAROCHE-SRV'.

Instructions d’utilisation

  1. Créez une organisation OpenObserve par compagnie et un compte d’ingestion limité à cette organisation.
  2. Dans Centre des journaux, ajoutez une destination Syslog : serveur 127.0.0.1, port 5514, TCP, format IETF RFC5424, SSL désactivé.
  3. Enregistrez, utilisez le test Log Center, puis vérifiez ici la réception et l’envoi.

Le tronçon local reste sur le NAS. Les journaux sortants utilisent HTTPS avec validation TLS. En cas de panne distante, ils sont conservés jusqu’à 128 MB ; les plus anciens peuvent ensuite être supprimés pour protéger le stockage.
